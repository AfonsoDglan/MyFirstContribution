# 🚀 Primeira Contribuição

Um repositório de **treino** para você fazer sua primeira contribuição open source, sem medo de errar.

Aqui você vai passar pelo mesmo caminho de um projeto open source de verdade:

> ler as regras → escolher uma issue → fazer fork → criar uma branch → commitar → abrir um Pull Request → conversar com quem mantém o projeto → ter seu PR aceito 🎉

Quando seu PR for aceito, seu nome aparece no **mural de participantes** (o site deste repositório).

---

## 📂 O que tem aqui

| Arquivo / pasta | Para que serve |

| `README.md` | Este arquivo. A porta de entrada de qualquer projeto. |

| `linguagens.md` | Desafio extra: aqui os conflitos acontecem. |
| `COLINHA.md` | Os comandos que você vai usar hoje. |

## 🧭 Por onde começar

1. Leia o [CONTRIBUTING.md](CONTRIBUTING.md) **inteiro**. Sério. Ele tem uma regra que muita gente pula.
2. Vá na aba **Issues** e filtre por `good first issue`.
3. Siga o passo a passo do CONTRIBUTING.

Travou? Abra uma issue usando o modelo **"Preciso de ajuda"** ou chame a pessoa instrutora. Errar faz parte. Este repositório existe para isso.

## 🌍 E depois?

Quando terminar aqui, procure um projeto de verdade:

- [goodfirstissue.dev](https://goodfirstissue.dev)
- [up-for-grabs.net](https://up-for-grabs.net)
- Busca no GitHub: `is:issue is:open label:"good first issue" language:python`

Feito com 💜 para quem está começando.
