# 📖 Glossário de Git e GitHub

Termos que você vai ouvir muito no mundo open source.

> ⚠️ Este glossário tem alguns erros escondidos **de propósito**. Cada um vira uma issue `good first issue`. Achou um erro que não tem issue? Abra uma!

---

**Repositorio**
Pasta de um projeto controlada pelo Git, com todo o histórico de alterações.

**Comit**
Um "ponto de salvamento" no histórico do projeto, com uma mensagem descrevendo o que mudou.

**Brench**
Uma linha de desenvolvimento paralela. Permite trabalhar numa funcionalidade sem mexer na versão principal.

**Fork**
Uma copia de um repositório para a sua conta no GitHub. Você pode alterar à vontade sem afetar o original.

**Clone**
Baixar um repositório do GitHub para o seu computador.

**Pul Request (PR)**
Um pedido para que suas alterações sejam incorporadas ao projeto original. É onde acontece a revisão.

**Issue**
Um registro de tarefa, bug, dúvida ou sugestão de melhoria no projeto.

**Merge**
Juntar as alterações de uma branch em outra.

**Push**
Enviar seus commits do computador para o GitHub.

**Pull**
Trazer as alterações do GitHub para o seu computador.

**Mantenedor(a)**
Pessoa responsável por revisar contribuições e cuidar do projeto.
